Source: https://github.com/google/material-design-icons

- part_wiper.xml: windshield_defrost_front
- part_oil.xml: oil_barrel
- part_brake.xml: disc_full
- part_tire.xml: tire_repair
- part_hvac.xml: climate_mini_split
- part_filter.xml: air_purifier

SVG path data is unchanged; Android VectorDrawable wraps the original viewport with a translation.

vehicle_tucson.png is a background-removed image derived with ImageGen from the vehicle reference supplied by the user on 2026-10-26. The reference is preserved at design/reference/tucson-user-reference.png. The user identified this vehicle as the new Tucson; using its image does not automatically choose a model year, powertrain, or manufacturer maintenance schedule.

The six consumable_*.png images are AI-generated studio product illustrations created with the built-in ImageGen tool on 2026-10-26. They illustrate maintenance categories and do not identify OEM part numbers fitted to the user's Tucson. Prompts and saved paths are recorded in design/consumable-assets.json.

The compact detail toolbar also uses Google Material Symbols more_horiz under the same Apache License 2.0; path data is preserved in drawable/ic_more_horiz.xml.
